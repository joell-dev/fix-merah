# ⚡ API Mailer – Lightweight Node.js Email Service

Sebuah email API minimalis yang dirancang buat perform, simple di-setup, dan gampang di-deploy ke Vercel maupun VPS.  
Project ini dibuat dengan pendekatan clean-code, modular, dan siap dikembangkan jadi service production grade.

---

## 🚀 Fitur Utama
- 📩 **Send Email API** (POST /api/send)
- 🔐 **Config terpisah** (environment-ready)
- 📁 **Log penyimpanan otomatis** untuk tracking
- ⚡ **Response cepat & low overhead**
- 🛠️ Struktur project rapi dan scalable
